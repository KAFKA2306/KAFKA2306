## Owner principles

- **Asset over activity.** commit数やrepo数ではなく、再利用できるSKU・データ・skill・distribution・decision evidenceを増やす
- **One authority per responsibility.** 同じ責務のregistry、workflow、config、documentationを複製しない
- **Evidence before claims.** 一次情報・取得時点・入力へ戻れる形でデータを扱う
- **Unknown stays unknown.** failure / unknown / unverifiedを正常値や0で埋めない
- **Completion has layers.** implementation / CI / deployment / production / external outcomeを別々に検証する
- **Owner time is a cost.** 同じ入力から再実行できる仕組みを優先し、one-off手作業を資産価値として数えない
- **External outcomes stay observational.** 売上・利用者・adoptionは観測できた時だけ記録し、repository完成のために捏造しない

## Repository boundary

このrepositoryの責務はGitHubプロフィールの入口だけです。portfolioの状態管理、商品状態、データ正本、release判定は各owner repository、GitHub、deployment、productionへ置きます。
